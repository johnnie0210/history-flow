# 한국사 흐름

한국사의 큰 흐름을 **카드 뒤집기**와 **퀴즈**로 익히는 앱입니다.
휴대폰 홈 화면에 설치(PWA)하면 오프라인에서도 쓸 수 있습니다.

- 배포 주소: https://johnnie0210.github.io/history-flow/

## 기능

- **📇 카드**
  - 흐름 카드: 앞면 "황산벌 전투 → 다음은?", 뒷면 "백제 멸망"과 설명, 앞뒤 단계
  - 짝 카드: 앞면 "1차 갑오개혁", 뒷면 "군국기무처 설치"
  - 주제 카드: 앞면 주제 이름, 뒷면 전체 흐름 타임라인
  - 범위(전체 / 시대 / 주제), 섞기, 좌우 스와이프, "외웠어요" 표시와 외운 카드 숨기기
- **❓ 퀴즈**
  - 유형: 다음 사건 / 빈칸 / 순서 맞추기 / 설명 보고 고르기 / 짝 맞추기 / 섞어서
  - 문제 수 10·20·50·전체, 무작위 또는 자주 틀린 것부터
  - 결과와 오답 목록, 틀린 것만 다시 풀기
- **📜 흐름 보기**: 주제별 타임라인, 시대 필터, 검색
- **학습 기록**: 외운 카드, 시대별 정답률 (이 기기에만 저장)

## 내용 고치기

내용은 모두 `content.md` 한 파일에 있습니다. GitHub에서 이 파일을 열어 연필 아이콘으로 고치고
**Commit changes** 를 누르면 1~2분 뒤 앱에 반영됩니다. 앱은 인터넷이 될 때 최신 내용을 먼저 받아옵니다.

```
# 시대                        시대 묶음 (고대, 고려 …)
## 제목                       주제
흐름: A → B(설명) → C         순서. 괄호 안은 카드 뒷면 설명
흐름(이름): A → B → C         이름 붙은 흐름 (한 주제에 여러 개 가능)
핵심: A → B → C               꼭 기억할 요약 (주제 카드에만 표시)
짝: 앞면 = 뒷면               짝 카드·짝 맞추기 문제
설명: ...                     바로 위 짝의 추가 설명
오답: 가, 나, 다              바로 위 짝 문제에 꼭 넣을 함정 보기
메모: ...                     참고 사항
```

- 흐름의 순서가 곧 퀴즈 정답입니다. 순서를 바꿀 때 주의하세요.
- 괄호 안의 `→`는 단계 구분으로 보지 않습니다. 예: `교조신원운동(삼례집회 → 서울 복합상소)`

## PC에서 확인

```powershell
npx serve .            # 표시된 주소를 브라우저로 열기
node --test test/core.test.js
```

`index.html`을 파일로 바로 열면 `content.md`를 읽지 못합니다. 위처럼 웹 서버로 열어 주세요.

## 배포 (GitHub Pages)

저장소 **Settings → Pages** 에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 지정합니다.

## 휴대폰에 설치

- **Android(Chrome)**: 주소 접속 → ⋮ → **홈 화면에 추가** 또는 **앱 설치**
- **iPhone(Safari)**: 주소 접속 → 공유 → **홈 화면에 추가**
